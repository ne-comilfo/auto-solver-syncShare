# Надстройка для SyncShare

Одно нажатие на иконку расширения выбирает варианты на **текущей странице** теста Moodle по разделу «Статистика» установленного SyncShare.

Правило выбора:

1. Если есть зелёные варианты, выбрать среди них вариант с максимальным числом выборов.
2. Если зелёных нет, выбрать вариант с максимальным числом выборов среди всех.
3. При равенстве максимальных значений ничего не менять для этой подсказки.

Работает с radio и checkbox. Если у вопроса несколько независимых подсказок (например, отдельная для каждого checkbox), правило применяется к каждой. Надстройка не отправляет тест и не переходит между страницами.

## Установка в Chrome

1. Установить и включить [SyncShare](https://chromewebstore.google.com/detail/syncshare/lngijbnmdkejbgnkakeiapeppbpaapib).
2. Открыть `chrome://extensions`, включить «Режим разработчика» и нажать «Загрузить распакованное расширение».
3. Выбрать эту папку, в которой находится `manifest.json`.
4. Открыть страницу прохождения теста Moodle (`/mod/quiz/attempt.php`) и дождаться статистики SyncShare.
5. Нажать иконку «SyncShare: заполнить по статистике». Результат появится в правом нижнем углу страницы.

Для следующих страниц теста повторить нажатие. После обновления файлов расширения нажать «Обновить» в `chrome://extensions`.

## Как устроено

Надстройка использует только разрешения `activeTab` и `scripting`: доступ к странице появляется после нажатия на иконку. Запросов в сеть и доступа к данным аккаунта SyncShare у неё нет. Она читает показанное SyncShare меню статистики через [Chrome DOM API](https://developer.chrome.com/docs/extensions/reference/api/dom) и запускает то же действие, что при ручном выборе пункта меню. Проверена по разметке SyncShare 2.19.0; если разработчик изменит разметку, обработку меню потребуется обновить.
