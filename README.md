# Надстройка для SyncShare

Расширение автоматически добавляет на страницу кнопку «Заполнить по статистике», когда SyncShare показал свои меню. Нажатие выбирает варианты на **текущей странице** по разделу «Статистика». Адрес сайта и класс вопроса в коде не зашиты: надстройка находит иконки SyncShare по всей странице, открывает каждое меню и выбирает вариант по правилу ниже.

Правило выбора:

1. Если есть зелёные варианты, выбрать среди них вариант с максимальным числом выборов.
2. Если зелёных нет, выбрать вариант с максимальным числом выборов среди всех.
3. При равенстве максимальных значений ничего не менять для этой подсказки.

Правило применяется к каждой найденной подсказке, в том числе если иконка стоит отдельно от поля ответа. Если пункт меню SyncShare допускает вставку ответа, надстройка запускает его действие. Она не отправляет тест и не переходит между страницами.

## Установка в Chrome

1. Установить и включить [SyncShare](https://chromewebstore.google.com/detail/syncshare/lngijbnmdkejbgnkakeiapeppbpaapib).
2. Открыть `chrome://extensions`, включить «Режим разработчика» и нажать «Загрузить распакованное расширение».
3. Выбрать эту папку, в которой находится `manifest.json`.
4. Открыть страницу теста и дождаться статистики SyncShare.
5. Нажать кнопку «Заполнить по статистике» в правом нижнем углу страницы. Также можно нажать иконку расширения на панели браузера.

Для следующих страниц теста повторить нажатие. После обновления файлов расширения нажать «Обновить» в `chrome://extensions`.

В Яндекс Браузере откройте `browser://extensions`, включите режим разработчика и загрузите эту же папку как распакованное расширение. SyncShare должен быть установлен в том же браузере. После обновления расширения разрешите ему работать на сайтах и обновите вкладку с тестом.

## Как устроено

Надстройка автоматически запускает свой скрипт на страницах HTTP и HTTPS, чтобы показать кнопку при появлении SyncShare. Это требует разрешения работать на сайтах. Запросов в сеть и доступа к данным аккаунта SyncShare у неё нет. Она читает показанное SyncShare меню статистики через [Chrome DOM API](https://developer.chrome.com/docs/extensions/reference/api/dom) и запускает то же действие, что при ручном выборе пункта меню. Проверена по разметке SyncShare 2.19.0; если разработчик изменит разметку, обработку меню потребуется обновить. Сам SyncShare в этой версии встраивается на страницы Moodle с любым доменом. На другом движке надстройка сможет работать только там, где SyncShare действительно показывает свои меню статистики.
